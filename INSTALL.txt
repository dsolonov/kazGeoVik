NomadQuest — админка с сохранением на сервер
Обновление: совместимость с изоляцией сайта на Timeweb, 08.10.2026

ИСПРАВЛЕНИЕ ОШИБКИ «Жеке қапшық жасалмады»

Если при первой установке появилась эта ошибка, замените рядом с игрой
два файла: admin-api.php и admin-config.php из папки upload этого архива.
Затем обновите admin.html. Код активации ниже остался прежним.
Не меняйте только private_dir в старом обработчике: обновляются ОБА файла.

БЫСТРАЯ УСТАНОВКА

1. Сохраните на компьютере копии текущих locations-info.json и locations.txt.
2. В настройках сайта на хостинге включите PHP 8.3 или 8.4.
   Минимальная версия для этого обработчика — PHP 8.1. Сайт открывайте по HTTPS.
3. Из папки upload загрузите рядом с index.php (или index.html) игры:
   • admin.html — замените прежнюю админку;
   • admin-api.php — серверный обработчик;
   • admin-config.php — его настройки.
   Загружайте именно три файла, а не всю папку upload отдельным каталогом.
   В этой же папке должны находиться locations-info.json и locations.txt.
   Файлы игры, её стили и service-worker.js менять не нужно.
4. Откройте https://ВАШ-ДОМЕН/admin.html, например:
   https://cd912546.tw1.ru/admin.html
   После замены старого admin.html обновите страницу Ctrl+F5.
5. При первом входе введите код активации из следующего блока и придумайте
   собственный пароль (не менее 10 символов). Повторите пароль и подтвердите.
   В дальнейшем для входа нужен только выбранный пароль.

КАК СОХРАНЯТЬ

При входе админка автоматически читает оба файла с сервера. Отредактируйте
локацию и нажмите зелёную кнопку «Сақтау» («Сохранить»). Дождитесь сообщения
«Сақталды»: после этого сервер обновил locations-info.json и locations.txt.
Ctrl+S выполняет то же действие. «Көшірме жүктеу» скачивает копию на компьютер
и не заменяет сохранение на сервер.

Названия, адреса, описания и обе подсказки доступны на казахском и русском.
Интерфейс админки — на казахском. При изменении координат автоматически
обновляются связанные игровые точки. «Ойынға енгізу» включает локацию в игру;
«Кезеңдер реті» меняет порядок раундов. Остальные поля справочника сохраняются.
Проверяйте доступность панорамы отдельно: редактор не проверяет Яндекс API.

После сохранения заново откройте игру, чтобы она прочитала новые данные.
Уже начатая игра продолжает использовать данные, загруженные при старте.
Редактор не меняет правила, штрафы, API-ключи и таблицу результатов игроков.

ЧТО ПРОВЕРИТЬ ПРИ ПЕРВОМ ЗАПУСКЕ

• Войдите и убедитесь, что видны прежние локации и порядок раундов.
• Внесите небольшое изменение текста, нажмите «Сақтау», затем
  «Серверден оқу». Изменение должно остаться. Верните текст, если нужно.
• Откройте игру заново и проверьте подсказку/справку изменённой локации.
• Нажмите «Шығу» и убедитесь, что для редактирования снова требуется пароль.

РЕЗЕРВНЫЕ КОПИИ И КОНФЛИКТЫ

Перед каждой записью создаётся копия прежних двух файлов. Хранятся последние
20 копий. «Резервтік көшірмелер» → «Ашу» открывает выбранную версию в редакторе.
Проверьте её и нажмите «Сақтау», чтобы восстановить её на сервере.

Если другая вкладка или программа изменила файлы после их открытия,
сохранение будет остановлено. Скачайте свою копию через «Көшірме жүктеу»,
прочитайте актуальную версию через «Серверден оқу» и перенесите нужные правки.
Если связь оборвалась во время сохранения, не считайте результат подтверждённым:
сначала скачайте свои изменения, затем перечитайте сервер и проверьте их.

Каждый файл записывается через временный файл и замену. При ошибке записи
обработчик пытается восстановить предыдущую пару. После аварийного прерывания
восстановление выполняется при следующем запросе к admin-api.php.

ГДЕ ХРАНЯТСЯ ПАРОЛЬ И КОПИИ

Новая версия создаёт папку nomadquest-private рядом с admin-api.php,
то есть внутри каталога игры. Выход за пределы public_html не требуется.
Изоляцию сайта и ограничения PHP отключать не нужно.

Хеш пароля, резервные копии и журнал восстановления сохраняются в файлах
с расширением .php. Каждый такой файл начинает выполнение с ответа 404
и немедленного завершения; следующие за защитным кодом данные не выводятся
и не исполняются. Временные файлы служебных данных защищены тем же способом.
Дополнительно создаются .htaccess с запретом доступа и закрытый index.php.
Обработчик читает данные через файловую систему, а не через HTTP.

В этой папке находятся auth.php (хеш пароля), attempts.php (счётчик попыток),
write.php (блокировка), временный pending.php (журнал) и папка backups.
Файлы сеансов хранятся стандартным обработчиком PHP, настроенным хостингом;
админка не размещает открытые файлы sess_* в публичной папке.

Проверка после установки пароля: откройте в отдельной вкладке адрес
https://ВАШ-ДОМЕН/nomadquest-private/auth.php — ожидается 403 или 404
без содержимого файла. Если виден код PHP или данные, прекратите использование
и обратитесь в поддержку хостинга для настройки исполнения PHP.

Эта версия рассчитана на исправление ошибки ПЕРВОЙ установки. Если старая
админка уже работала, переносить её служебную папку вручную в public_html
нельзя: старые auth.json, резервные JSON и sessions не имеют новой защиты.
При переходе на новую папку пароль задаётся заново тем же кодом активации;
история копий из старой папки автоматически не переносится. Файлы игры
и текущий справочник переходом не заменяются.

ЕСЛИ СОХРАНЕНИЕ ИЛИ ВХОД НЕ РАБОТАЕТ

1. Сообщение о PHP / ответе не в JSON:
   убедитесь, что загружены оба PHP-файла, PHP включён для данного сайта,
   используется поддерживаемая версия. Открывать admin.html как локальный
   файл на компьютере нельзя. На GitHub Pages этот PHP-обработчик не работает.

2. Нельзя создать служебную папку / private_dir:
   в admin-config.php должно быть:

   'private_dir' => __DIR__ . '/nomadquest-private',

   При обновлении замените также admin-api.php, а не только настройку.
   Если ошибка осталась, попробуйте создать пустую папку nomadquest-private
   через файловый менеджер рядом с admin-api.php. PHP должен иметь права
   записи в неё и в папку игры. Не ставьте права 777.
   При повторной ошибке пришлите строку из журнала PHP с mkdir(): она поможет
   отличить ограничения доступа, неверного владельца и нехватку места.

3. Нет прав на запись данных:
   проверьте владельца и права каталога игры: обработчик создаёт временные
   файлы в этой папке и заменяет оба файла данных. Если сайт перенесён из
   другого аккаунта, помощь хостинга может понадобиться для исправления владельца.

4. Сессия завершилась:
   войдите ещё раз на этой же странице. Несохранённые правки остаются в памяти
   вкладки; не обновляйте страницу до их сохранения или скачивания.
   Сеанс заканчивается после 30 минут без обращений к серверу, максимум — 8 часов.
   После пяти неверных попыток входа с одного IP подождите 15 минут.

5. Админка требует HTTPS, хотя адрес уже начинается с https:
   обратитесь в поддержку хостинга, чтобы PHP корректно получал признак HTTPS
   от сервера. Пароли через обычный HTTP обработчик не принимает.

6. При ошибке 500 смотрите журнал PHP в панели хостинга. Не включайте публичный
   вывод ошибок PHP на действующем сайте.

СМЕНА И СБРОС ПАРОЛЯ

После входа нажмите «Құпиясөз» и введите текущий и новый пароли. Смена пароля
завершает доступ для других открытых сеансов при их следующем обращении.

Если пароль забыт: через файловый менеджер хостинга удалите только auth.php
из папки nomadquest-private. Снова откройте admin.html, используйте код активации из
этой инструкции и задайте новый пароль. Копии данных не удаляйте. При переносе игры переносите вместе с ней папку nomadquest-private,
чтобы сохранить пароль и историю копий.

ПРОВЕРКИ КОМПЛЕКТА

Проверены JavaScript и 30 сценариев редактора: совместимость с 38 записями
справочника и игровым списком, двуязычное редактирование, изменение координат,
отправка сохранения, конфликты, истечение сессии, восстановление из копии.
Для сценариев API использованы тестовые ответы. Обновлённый PHP-код проверен чтением;
PHP-среды и браузера для полного запуска здесь не было. Поэтому выполните
проверку первого сохранения на хостинге по инструкции выше.
